# Contributing

Thanks for your interest! This project is part of my portfolio and I welcome
issues, suggestions and pull requests.

## Getting started

1. Fork the repository and create a branch: `git checkout -b feat/my-change`
2. Make your changes, adding tests when applicable.
3. Run the checks locally (see the repository README).
4. Open a Pull Request describing **what** and **why**.

## Commit conventions

This project follows [Conventional Commits](https://www.conventionalcommits.org/):
`feat`, `fix`, `docs`, `refactor`, `test`, `ci`, `chore`.

## Pull Requests

- Keep PRs focused and small.
- Reference related issues.
- Make sure the CI is green.

## Code of Conduct

By participating, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
